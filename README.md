# 🎮 Elemental Twins  
### 2D 슈팅 퍼즐 플랫포머 게임

## 🎯 게임 소개

**2D 퍼즐 플랫포머 게임입니다**입니다.

- 플랫폼: PC  
- 개발 엔진: Unity 2022
- 개발 기간: 2025.07.07 ~ 2025.07.17
- 개발 인원: 1인 프로젝트

<br><br>

---

플래시 게임 'Firegirl and Waterboy'를 레퍼런스로 하여 액션 요소를 가미한 2D 게임입니다.
<br>
Enemy의 행동은 FSM 기반으로 구현하여 상태 전환을 명확히 관리했습니다.
